Kit articulations

Each row is a GMD note and each column a kit. A cell plays the draft sound from rendering.kits first, then the alternatives from config/kit_auditions.yaml. The buttons play one hit at each velocity. Pick the sound that fits; to use a key that isn't offered, find it under All sounds and type it in other (e.g. 64 or 42 cc4=0). Picks stay in this browser. Export the CSV when you're done.

Esc stops playback.
